Proyecto: Piaget-01 — Next.js + Tailwind + Decap CMS (full-width + admin fijo)
=============================================================================

Comandos
- npm install
- npm run dev                     # http://localhost:3000
- npm run build                   # exporta a /out
- npx decap-server                # backend local del CMS (8080)

Abrir el CMS
1) Terminal A: npm run dev
2) Terminal B: npx decap-server
3) Navegador: http://localhost:3000/admin/index.html  (o /admin/)

Notas técnicas
- 'output: "export"' ⇒ no usamos redirects; entra directo a /admin/index.html
- index del admin trae init manual (window.CMS.init) para evitar pantalla en blanco.
- Navbar, secciones y páginas usan w-full + paddings → aprovechan TODO el ancho.
- El video hero usa un MP4 de demo vacío: reemplázalo por uno real para evitar 416 en consola.
- Páginas: /maternal, /kinder, /primaria, /secundaria, /preparatoria, /menu1, /menu2.
